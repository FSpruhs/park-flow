# Parking Inventory Bounded Context

Specific terms related to parking inventory.

| Term                  | Definition                                                                                             |
|-----------------------|--------------------------------------------------------------------------------------------------------|
| Parking Spot          | A physical location where a vehicle may park. Managed by the ParkingSpot Aggregate.                    |
| Parking Spot Type     | Classification of a parking spot (e.g., Rentable, Disabled, Electric).                                 |
| Rentable Parking Spot | A parking spot type that requires a price and can be rented by a customer for a month.                 |
| Disabled Parking Spot | A parking spot reserved for drivers with disabilities. Cannot be rentable.                             |
| Electric Parking Spot | A parking spot equipped with an electric charging station, reserved exclusively for electric vehicles. |
| Parking Spot Price    | The monthly monetary value associated with renting a parking spot in EUR.                              |
| Parking Spot State    | Indicates whether a parking spot is active or inactive.                                                |
| Parking Spot Name     | Human-readable identifier for a parking spot, e.g., "P-1" or "S-12".                                   |
| Gate                  | An entry or exit gate controlling vehicle access to the parking area.                                  |
| Gate Type             | Whether the gate is an Entrance or an Exit.                                                            |
| Gate Name             | Human-readable identifier for a gate                                                                   |
| Gate State            | Indicates whether a parking spot is active or inactive.                                                |
